# 🧠 State Management (Zustand)

У цьому каталозі зберігаються всі глобальні стани додатка, реалізовані за
допомогою **Zustand**.

## 🛠 Загальні принципи

1. **Persistence**: Стори використовують `persist` middleware тільки для
   збереження мінімально необхідних даних (наприклад, тільки статус
   `isAuthenticated`). Це баланс між зручністю (UX) та приватністю.
2. **Hydration**: Для сторів із `persist` обов'язково використовується прапорець
   `_hasHydrated`. Це дозволяє показувати скелетони замість "стрибаючих"
   елементів інтерфейсу під час завантаження даних із `localStorage`.
3. **Proper Typisation**: Всі стейти та дії мають бути чітко типізовані.
