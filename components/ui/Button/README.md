📄 Документація компонента Button Базовий компонент кнопки. Підтримує стани
завантаження, різні візуальні варіанти та повну адаптивність.

🛠 Параметри (Props) variant ('primary' | 'secondary') — за замовчуванням
'primary'.

- primary: Темно-зелена кнопка.

- secondary: Сіра кнопка з рамкою.

- isLoading (boolean) — якщо true, текст змінюється на "Завантаження...", а
  кнопка стає неактивною.

- disabled (boolean) — стандартне вимкнення кнопки.

- children (ReactNode) — контент (текст, іконки).

- className (string) — для додаткових зовнішніх стилів.

- ...props — усі стандартні атрибути <button> (onClick, type, form тощо).

🚀 Приклади використання (з макетів)

1. Кнопка "Переглянути статтю" (У картці) Використовується в блоках зі списком
   статей. Має світло-зелений фон, щоб не перевантажувати інтерфейс картки.

Код: TypeScript import { Button } from '@/components/ui/Button/Button';

<Button variant="secondary">
  Переглянути статтю
</Button>

2. Кнопка "Показати ще" (Пагінація)

Темно-зелена кнопка, що є головною дією на ділянці сторінки. Логіка адаптації:
На мобільних пристроях вона займає всю ширину (335px Fill), а на планшеті та
десктопі автоматично підлаштовується під контент (133px Hug / 160px Hug).

TypeScript // variant за замовчуванням "primary" <Button> Показати ще </Button>

3. Кнопки в Хедері (Вхід / Реєстрація) Демонструє використання двох варіантів
   поряд для створення ієрархії дій.

<div style={{ display: 'flex', gap: '8px' }}>
  <Button variant="secondary">Вхід</Button>
  <Button>Реєстрація</Button> 
</div>
